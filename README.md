# Alfresco Scripting Showcase

📦 **Что здесь?**
Коллекция скриптов для Alfresco JavaScript Console, которые я разработал для автоматизации рутинных задач.

🔧 **Основные функции:**  
- Выгрузка штатного расписания в CSV.
- Фильтрация сотрудников по отделам/ролям.

🚀 **Для кого?**
- Администраторы Alfresco.
- Разработчики, изучающие API Alfresco.
- HR-отделы, работающие с оргструктурой.
